# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful; no harassment, trolling, or personal attacks; assume good faith; critique code and claims, not people. Honest technical disagreement is welcome here, including about this project's own claims.

Maintainers may remove, edit, or reject contributions and interactions that violate this code, and will communicate reasons when moderation happens.

Report unacceptable behavior to **hello@troth.one**. Reports are handled confidentially.
