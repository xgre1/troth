Settings
Operator passphrase
One secret opens two locks: the operator key that signs, and the credential vault that holds your logins. Changing it re-wraps both in the same operation — if the vault half fails, the key change is rolled back, so the two can never end up on different passphrases. The vault locks afterwards; unlock it again with the new one.
Local LLM server
Your local OpenAI-compatible server (llama.cpp, Ollama, LM Studio — anything speaking /v1). The Local engine answers through it when enabled. Restart the proxy after changing.
Network
Which interface the proxy listens on. Keep 127.0.0.1 unless you need remote access over Tailscale / LAN. Restart the proxy after changing.
One mind, many devices
Your memory lives on one machine and follows you on every other. how it worksi
The mind machine: the computer that keeps your memory, usually the one that is always on. It announces itself on your network with a name and a door, never a secret.
Any other device: runs Set up, sees that machine by name, asks to follow. Nothing happens until you approve on the mind machine.
Different networks? Set up hands you a pairing code that carries every address the mind machine answers on, over Tailscale or any private mesh.
Offline: every device carries the full mind, so everything keeps working. What you say while apart queues and reconciles by itself when the machines meet again.
Lost a device? Revoke it below. One click, only that device dies.
Public Wi-Fi: being on it is fine; pairing over it is not. On an untrusted network the connection between your machines is not encrypted, so pair and sync at home or over a private mesh like Tailscale, which encrypts everything wherever you sit.

Wire the troth MCP into Claude Code so it can read your substrate, cache, and tools. One click installs the troth@troth plugin from the xgre1/troth marketplace.
troth MCP (Claude Code): checking… 


      

        What changes inside Claude Code once troth is mounted:

        shell commands run through troth-bash (no permission prompts), file edits through
        troth-hashline (anchored, AST-checked), repeated reads through troth-cache —
        Claude's own Bash/Edit are redirected to these, so troth's tools are the ones that run.
        Memory tools (recall, engram_record, dialogue) are added alongside,
        and browse hands it a real Chrome it can drive: navigate, read the DOM, click and
        fill, screenshot. A private-profile browser starts on demand; your logged-in one stays out of
        reach unless you opt in from the Browser card below.
        Turn any of it off in ~/.troth/config.json: {"features":{"bash_steer":false,"edit_steer":false}}.

Orchestration — spawn sub-workers from inside a session

    

      

        
troth_orchestrate_triage

        
Pre-check whether a task warrants spawning role-specialist sub-agents. Cheap heuristic; returns inline | ask_user | explicit_request. Call before orchestrate_run.

        
mcp

      

      

        
troth_orchestrate_run

        
BLOCKING: plan → DAG dispatch → wait (up to 10 min). Use for short orchestrations. For longer, use orchestrate_start + orchestrate_status/summary.

        
mcp

      

      

        
troth_orchestrate_start

        
Async: spawn workers, return group_id immediately. Poll with orchestrate_status({group_id}); finalize with orchestrate_summary({group_id}); cancel with orchestrate_kill.

        
mcp

      

    

    

      Claude Code picks these tools via LLM tool-use reasoning when the user describes a multi-domain task. There is NO deterministic natural-language interceptor — the LLM decides. For deterministic team dispatch from inside a session, use /agent <a>,<b> <task> instead.
