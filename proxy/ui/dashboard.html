troth CLI — substrate-native (primary)

    

      

        
troth cli

        
Interactive REPL backed by the substrate brain. Slash commands (/goal, /remember, /recall, /context, /think, /agent, /compact, /init, …) execute against substrate directly. Bypasses claude entirely. Picks transport from --llm flag or TROTH_ENTITY_LLM env (default: router).

        
local

      

      

        
troth cli --llm llamacpp --agent-id work

        
Pin a transport + scope substrate identity to a named sub-brain (separate engram pool). --llm: router | llamacpp | ollama | anthropic | codex_oauth. --agent-id: any tag.

        
local

      

      

        
troth codex login

        
One-time browser OAuth — sign in to ChatGPT so the entity transport can route through your Plus/Pro subscription (flat-rate, no per-token billing). Logout / status with same prefix.

        

      

      

        
troth config set default_command cli

        
Make the bare troth command drop into the substrate REPL (vs. the legacy "spawn Claude Code through the proxy" path). Persisted to ~/.troth/config.json.

In-session — slash skills (substrate-native, deterministic)

    

      

        
/agent

        
List registered sub-brains. /agent <name> + creates. /agent <a>,<b> <task> dispatches a team in parallel. /agent stop cancels. Aliases: /agents /team /create /brains /switch all route here.

        
substrate

      

      

        
/goal <statement>

        
Pin a high-salience goal as a substrate anchor. Surfaces in identity prefix on every subsequent turn until cleared.

        
substrate

      

      

        
/remember <fact>

        
Persist a fact to substrate semantic memory (engram). Verified against existing engrams via TMMA write-time QC.

        
substrate

      

      

        
/recall <query>

        
Multi-axis substrate retrieval (semantic + temporal + causal + entity). Returns ranked engrams + dialogue snippets.

        
substrate

      

      

        
/context

        
Snapshot: active goals + recent decisions + dialogue tail + identity. Read-only, deterministic, <50ms.

        
substrate

      

      

        
/init

        
Scan cwd, write project anchors to substrate (one-time per project). LLM-driven + auto-persists.

        
substrate

      

    

    

      Slashes work in: troth cli REPL · any MCP host (Claude Code / Cursor / Aider) calling troth_slash_invoke.
    

  


  

    
In-session — orchestration (MCP tools, LLM-routed via Claude Code)

    

      

        
troth_orchestrate_triage

        
Pre-check whether a task warrants spawning role-specialist sub-agents. Cheap heuristic; returns inline | ask_user | explicit_request. Call before orchestrate_run.

        
mcp

      

      

        
troth_orchestrate_run

        
BLOCKING: plan → DAG dispatch → wait (up to 10 min). Use for short orchestrations. For longer, use orchestrate_start + orchestrate_status/summary.

        
mcp

      

      

        
troth_orchestrate_start

        
Async: spawn workers, return group_id immediately. Poll with orchestrate_status({group_id}); finalize with orchestrate_summary({group_id}); cancel with orchestrate_kill.

        
mcp

      

    

    

      Claude Code picks these tools via LLM tool-use reasoning when the user describes a multi-domain task. There is NO deterministic natural-language interceptor — the LLM decides. For deterministic team dispatch from inside a session, use /agent <a>,<b> <task> instead.
