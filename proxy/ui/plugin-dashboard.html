What each number means

The plugin writes a row to ~/.troth/state.db every time a hook fires, compression occurs, or a tool output is archived. This page is the roll-up.

  • Hook activations — number of times each hook (LoopBreaker, VerifyFirst, editmatcher, ast-validate, critic, injector, output-sandbox…) ran. High numbers here mean the plugin is actually engaging your session.
  • Tokens saved — recorded to the savings_ledger: bash compression bytes, rescued edit-matcher calls, archived tool outputs, loopbreaker denials. Bytes → tokens uses /3.3.
  • Archive compression — implied savings from the SQLite/FTS5 sandbox. Raw vs summary bytes returned to the agent.
  • Substrate — row counts in action_records, the unified event store. Edits/reads/decisions/compacts each become one typed ActionRecord with verification, outcome, and a parent_id chain.
  • Precedent hits — turns where the injector's [troth/precedent] block was non-empty. This is the substrate actually surfacing prior verified work into a new prompt.
  • Compaction events — Layer 5 page-swap activity. Evicted working-set pages remain fetchable via fetch_action; they're not lost summaries.
  • AgentMarket — historical race outcomes aggregated across market_winner rows. Basis for future task-tier routing.
Reads directly from ~/.troth/state.db. No network calls. Refreshes every 10s.
